# Math Fact Quest v2

A simple browser-based math facts game for multiplication and division facts 1–12.

## Run it

Double-click `index.html` and open it in Chrome or Safari.

No server, AI, API key, token usage, or installation is required.

## Features

- Multiplication, division, and mixed practice
- Choose specific tables 1–12
- Practice mode
- Beat the Clock (60, 90, or 120 seconds)
- Mastery Challenge mode
- Correct / missed / streak / accuracy / points
- Missed facts are recycled back into practice
- Weak tables appear more frequently
- XP and levels
- Unlockable badges
- Best timed score
- Parent dashboard
- Most-missed facts
- Weakest tables
- Export progress to JSON
- Progress saved locally in the browser
- Simple sound feedback

## Progress storage

Progress is stored with browser `localStorage`.

If browser site data is cleared, progress will be lost. Use **Export Progress** from the Parent Dashboard if you want a backup.
